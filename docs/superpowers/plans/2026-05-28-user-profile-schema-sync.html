Project hiện dùng schema user/profile mới, không còn giữ legacy aliases, không fallback name/phone/avatar/password. Không dùng tài liệu này làm nguồn triển khai hiện tại.

User Profile Schema Sync Implementation Plan

For agentic workers: REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking.

Goal: Đồng bộ field user/profile giữa backend schema, app-mobile, web-admin, booking và ticket response.

Architecture: Backend dùng canonical fields mới nhưng giữ legacy aliases trong response để tránh phá UI hiện tại. Frontend chuyển sang đọc/gửi canonical fields và fallback legacy trong giai đoạn migration.

Tech Stack: Node.js, Express, Mongoose, Joi, React TypeScript, Expo React Native.

SPEC Disclosure

Autonomous Decisions

Triển khai theo hướng tương thích lùi: thêm field canonical fullName, phoneNumber, avatarUrl, passwordHash nhưng vẫn hỗ trợ legacy name, phone, avatar, password trong một giai đoạn.

Deviations

Không xóa ngay field legacy khỏi schema để tránh làm hỏng dữ liệu seed và database hiện có trước khi migration được chạy.

Trade-offs

Giữ mapping kép làm code tạm thời dài hơn, đổi lại backend và frontend có thể chạy với cả dữ liệu cũ lẫn mới.

Context/Notes

Ưu tiên sửa lỗi thực tế: booking/ticket đang trả fullName từ field không tồn tại và mobile đổi mật khẩu thiếu confirmPassword.
