# BeatCinema Admin Web

React/Vite admin dashboard for the BeatCinema movie-booking system.

## Runtime

- React 19
- TypeScript
- Vite
- Tailwind CSS
- Backend API prefix: `/api/v1`

## Local Development

```bash
npm install
npm run dev
```

Create `admin-web/.env` from `admin-web/.env.example` before running locally.

## Available Scripts

```bash
npm run dev
npm run build
npm run lint
npm run preview
```

## Active Areas

- Dashboard statistics
- Movie, cinema, room, showtime, booking, ticket, payment, user, and admin management
- Seat layout editor
- Profile and password management
